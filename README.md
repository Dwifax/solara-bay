Solara Bay is a full-featured open-world crime game built in WebGL with Three.js. Explore a neon-lit coastal city, engage in high-speed police pursuits, intense shootouts, and dynamic missions. Features a physics-driven vehicle system, AI pedestrians and enemies, procedurally-generated roads, radio stations, and a Rust/WebAssembly simulation core for optimal performance.

## Run it

```bash
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
