Solara Bay is an original open-world crime game that runs in the browser: a sunlit coastal city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted level with police pursuits and helicopters, story missions with cutscenes, gunplay with a weapon wheel, boats on the bay, a radio, a HUD with minimap, a start screen and saves. Static files only, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
